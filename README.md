# DOM Quiz App

A JavaScript DOM-based quiz application built for a Coding Temple assignment.

## 🔗 Live Demo
https://geniartbytelabs-spec.github.io/dom-quiz-app/

## Features
- Dynamic quiz rendering using JavaScript
- Option selection and submission flow
- Score calculation and final results screen

## Technologies Used
- HTML
- CSS
- JavaScript (DOM manipulation)

## How to Run Locally
Open index.html in your browser.
